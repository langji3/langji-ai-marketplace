# Cursor 安装与更新

按 [完整项目资源包](../../docs/project-installation.md) 同时安装：
- vendor/ai-dev-protocol/ 全部资源。
- .cursor/rules/ai-dev-protocol.mdc 短入口。

入口始终可见，普通问答不必读取开发阶段。代码和 Apifox 任务由 Router 分类，按需读取阶段。不要只复制 .mdc 后声称已安装完整规则。

在目标项目运行自检，打开新会话核验实际读取的 Router 路径，并在隔离练习项目验证讨论、小修改和完整需求。升级整体替换 vendor 并更新入口；卸载只移除本次安装的目录/规则，保留自定义内容。
