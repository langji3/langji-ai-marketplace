## AI Dev Protocol

原生 plugin 已安装时使用插件唯一的 ai-dev-protocol Router，按链接读取内部阶段。

手工完整接入时，从项目根目录读取 vendor/ai-dev-protocol/skills/ai-dev-protocol/SKILL.md。Router 及 phases、references、templates 必须存在。GitHub 地址表示来源，不等于已加载规则。项目业务规则、用户指令和宿主约束优先。

不要同时启用原生 plugin 和同名直装 skill。资源缺失时说明只安装了摘要，按安装说明补齐后再声称完整接入。
